# 烽火世紀 1936–1991

一款**簡化、對新手友善**的大戰略網頁遊戲：從二戰前夕（1936 年）一路打到冷戰結束（1991 年蘇聯解體）。
玩法類似「鋼鐵雄心」這類即時（可暫停）大戰略遊戲，但規則大幅簡化，並且**支援多人連線**。

- 🌍 **真實世界地圖**：563 個陸地地區、78 個海域，依 1936 年的歷史疆界劃分（地理資料來源：Natural Earth），有地形紋理、沿岸光暈與國界描邊。
- 🚩 **歷史國旗**：約 160 個國家都有國旗，並隨年代自動變化（例如中共旗→五星旗、義大利王國→共和國、加拿大紅船旗→楓葉旗）。國旗出現在地圖國名旁、部隊標誌與介面上。
- ⚔️ **大量戰爭**：二戰（西班牙內戰、中日戰爭、閃擊波蘭、法國戰役、巴巴羅薩、太平洋戰爭……）與冷戰各場熱戰（國共內戰、韓戰、越戰、中東戰爭、印巴戰爭、兩伊戰爭、福克蘭戰爭、波斯灣戰爭……），還有張鼓峰事件、法泰戰爭、英伊戰爭、印馬對抗、足球戰爭等。另可開啟**虛構戰爭**：AI 會向玩家提出領土要求，小國之間也會爆發邊境衝突。
- 📜 **尊重歷史**：約 200 個歷史事件依史實日期發生並附上簡短史實說明；殖民地依史實年份獨立；城市與國家名稱隨年代變更。AI 依照歷史做出選擇，**由你決定的事件則可以改寫歷史**。
- 🗞️ **世界大事視窗**：事件發生時畫面中央跳出視窗並**強制暫停**，每位玩家都能選擇回應（譴責、軍援、保證獨立、參戰、擴軍……），所有玩家做出選擇後自動繼續。
- 🔬 **科技樹**：約 180 項科技依真實年份排列（步兵與砲兵、裝甲、空軍、海軍、工業、電子與核子、軍事學說），沒有互斥科技，超前時代研究較慢。
- 🛡️ **更多兵種**：輕型／中型／重型坦克、主力戰車、機械化步兵、陸戰隊；戰鬥機、噴射戰鬥機、近接支援機、戰術轟炸機、戰略轟炸機、海軍轟炸機、武裝直升機；水面艦隊、航艦戰鬥群、潛艇。
- 🏛️ **國策樹**：參考鋼鐵雄心，德、義、日、蘇、英、法、美、中華民國、中共都有專屬國策樹，美、蘇、中、英、法、西德、臺灣另有冷戰國策，其他國家使用通用國策。有**互斥路線**，例如中華民國可以選「攘外必先安內」（對中共開戰、處決張學良）或「第二次國共合作」。
- 🧭 **五個劇本**：1936「風雨欲來」、1939「閃擊戰」、1950「韓戰風雲」、1962「核子邊緣」、1979「最後的對峙」。任何劇本都可以玩到 1991 年。
- 🤖 **新手友善**：互動教學、遊戲說明，以及可隨時開關的「AI 輔助」（自動國策 / 研究 / 生產，甚至 AI 指揮全軍）。
- 👥 **多人連線**：一人開房、分享 5 字元房間代碼，朋友加入後各自選國家。支援「伺服器中繼」與「點對點（P2P）」兩種方式。
- 📱 桌機與手機皆可遊玩（滑鼠／觸控）。全中文（繁體）介面。

## 立即開始

### 方法一：直接在網頁上玩（免安裝）

網址：<https://petersonailab.github.io/Iron-heart-5/>

第一次使用前，倉庫擁有者需要到 GitHub 專案的 **Settings → Pages**，把 **Source** 設為 **GitHub Actions**（只需設定一次）。之後每次推送，`.github/workflows/pages.yml` 都會自動把 `public/` 部署成網站。網頁版的多人連線請使用 **點對點（P2P）** 模式。

### 方法二：本機執行（支援所有功能，含伺服器中繼）

需要 [Node.js](https://nodejs.org/) 18 以上。

```bash
npm install
npm start
```

然後用瀏覽器開啟 <http://localhost:3000>。
同一個區域網路的朋友可以用你的區網 IP 連線（例如 `http://192.168.1.23:3000`），在主選單選「加入多人房間」，連線方式選「伺服器中繼」。

注意：要先下載專案（`git clone` 或在 GitHub 頁面下載 ZIP），在專案資料夾裡執行上面的指令；玩的時候終端機視窗不能關閉。

### 方法三：部署到雲端（讓遠方朋友用伺服器中繼連線）

任何支援 Node.js 的平台（Render、Railway、Fly.io、自己的 VPS……）都可以：
建置指令 `npm install`，啟動指令 `npm start`，伺服器會讀取 `PORT` 環境變數。

## 怎麼玩

| 操作 | 說明 |
| --- | --- |
| 暫停 / 繼續 | `空白鍵` 或畫面上方的 ⏸；`1`–`5` 調整速度 |
| 移動地圖 | 拖曳；滾輪縮放；手機可雙指縮放 |
| 選取部隊 | 點擊彩色部隊方塊（數字是師數）；`Shift`+點擊加選；`Shift`+拖曳框選 |
| 移動 / 進攻 | 選取部隊後**右鍵點擊**目標地區；手機用「移動/進攻」按鈕或長按地圖 |
| 分頁 | 政治 `Q`、研究 `W`、生產 `E`、外交 `R`、軍隊 `T` |

**核心規則（簡化版）**

- **時間**：即時進行，每秒 1～25 天，可隨時暫停下指令。
- **經濟**：工業（工廠）提供每日產能，扣除部隊維持費後平均分給各生產線。和平時期蓋工廠，戰爭時造兵。
- **法律**：經濟法與徵兵法決定動員程度；民主國家要等世界緊張度升高或開戰後才能全面動員。
- **戰鬥**：攻擊力 vs 防禦力，受地形、要塞、補給、制空權、防空、科技、壕溝影響。組織度歸零的守軍會撤退；**無路可退就會被包圍殲滅**。斷絕補給的部隊戰力大減並持續損耗。
- **海空軍**：艦隊爭奪制海權、保護運兵；潛艇破壞敵方海上運輸（降低生產）；戰鬥機爭奪制空權；近接支援機與轟炸機支援地面戰；戰略轟炸機轟炸敵方工業；海軍轟炸機與航艦攻擊航程內的敵艦。部隊可經海路運輸並進行**兩棲登陸**。
- **研究**：科技依真實年份排列，提早研究會變慢；工業規模小的國家研究也較慢。核武、氫彈、洲際飛彈等戰略科技需要大量投入。
- **國共內戰**：1936 年開局時國共仍處於內戰狀態。玩家扮演中華民國可以隨時進攻中共，並在「少帥的動向」與「西安事變」等事件中選擇處決張學良；內戰雙方（國共、南北韓、南北越、西班牙兩政權）宣戰只需少量政治點數。
- **投降**：一國被佔領的勝利點超過門檻就投降，被佔領地割讓給佔領者；盟軍解放淪陷國時該國會復國。也可以白和平、停火，或在對方投降時扶植傀儡政權。
- **核武**：研發後可生產核彈；擁有核武的國家遭核擊時會自動核子報復——冷戰的「相互保證毀滅」。

## 多人連線說明

0. 世界大事發生時所有玩家的遊戲都會暫停，等每位玩家都做出選擇後才繼續；主機也可以隨時手動繼續。
1. 主機在主選單按「建立多人房間」，選擇連線方式：
   - **伺服器中繼**：用本專案的 Node.js 伺服器（`npm start`）。最穩定。
   - **點對點 (P2P)**：不需要自架伺服器（適合 GitHub Pages）。少數公司／學校網路的防火牆可能擋住 WebRTC，這時請改用伺服器中繼。
2. 把畫面上的 **房間代碼** 告訴朋友；朋友按「加入多人房間」輸入代碼（連線方式要和主機相同）。
3. 每位玩家點選推薦國家或直接點地圖選國家，主機按「開始遊戲」。
4. 主機控制遊戲速度，任何玩家都能暫停；遊戲中可以聊天。中途離開的玩家，國家會交由 AI 接管；遊戲進行中也可以有新玩家加入。

技術上採「主機權威」架構：模擬只在主機的瀏覽器執行，客戶端送出指令並接收差異快照。

## 專案結構

```
public/                  遊戲網站（純靜態，可直接部署）
  index.html, css/       介面
  js/main.js             介面主程式（選單、大廳、面板、教學）
  js/ui/maprender.js     Canvas 地圖繪製與互動
  js/ui/trees.js         科技樹與國策樹
  js/ui/flags.js         國旗繪製（js/data/flags.js 為各國歷史國旗資料）
  js/ui/icons.js         兵種圖示
  js/core/               模擬引擎（瀏覽器與 Node 共用）
    engine.js            經濟、補給、移動、陸海空戰、投降與解放
    ai.js                電腦 AI（前線作戰、兩棲登陸、生產研究、外交）
    history.js           1936–1991 歷史事件與歷史導引
    worldevents.js       世界大事視窗、玩家反應、邊境危機與虛構戰爭
    scenarios.js         五個劇本
    commands.js          玩家指令
  js/net/net.js          多人連線（WebSocket 中繼 / PeerJS P2P）
  js/data/               地區、國家、規則、科技（tech.js）、國策（focus.js）、國旗、地圖資料
server/server.js         靜態網站 + WebSocket 中繼伺服器
tools/build-map.js       由 Natural Earth 產生地圖（npm run build:map）
tools/sim-test.js        無頭模擬測試（npm run sim -- 1936 10）
```

## 開發

```bash
npm run build:map          # 修改 public/js/data/regions.js 後重新產生地圖
npm run sim -- 1939 6      # 從 1939 劇本無頭模擬 6 年，檢查歷史走向與效能
```

## 關於歷史內容

本遊戲以教育與娛樂為目的，事件說明力求符合史實（包括南京大屠殺、納粹大屠殺、原子彈轟炸、大躍進饑荒、赤柬暴行等歷史悲劇的簡短紀錄），不美化任何極權政權或戰爭罪行。國旗以簡化圖形繪製；為避免散布仇恨符號，納粹德國時期的德國以 1933–1935 年間同樣是國旗的黑白紅三色旗呈現，不使用卍字旗，克羅埃西亞獨立國也不繪出烏斯塔沙標誌。虛構戰爭在事件中會標示「虛構事件」。
